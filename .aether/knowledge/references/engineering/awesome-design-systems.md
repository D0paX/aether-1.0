# Awesome Design Systems

- URL: https://github.com/alexpate/awesome-design-systems
- Category: engineering
- Relevance: Curated directory of production design system implementations for research and pattern discovery.
- Priority: supplementary

## Description

Awesome Design Systems is a community-maintained list of notable design systems,
pattern libraries, and UI guidelines from companies and open-source projects. It
catalogues how organizations structure their design tokens, component libraries,
documentation, and governance processes.

## Key Sections

- Company design systems: Atlassian, IBM Carbon, Shopify Polaris, GitHub Primer,
  Adobe Spectrum, and many others
- Open-source design systems: Community-driven design system implementations
- Design system tools: Tools for building, documenting, and maintaining design systems

## Usage Guidelines for Aether

**Use as reference for:**
- Design system research: When planning Aether's design token structure, component
  documentation, or governance process, use this list to study how established
  companies handle the same challenges
- Token architecture: Compare how different design systems organize their color,
  spacing, typography, and elevation tokens
- Component naming: Study naming conventions across design systems to ensure
  Aether's component names are intuitive and consistent with industry norms

**Do not adopt:**
- Any specific design system's visual style
- Any specific design system's token values
- Design system governance processes designed for large organizations (Aether
  is a single-product project, not a multi-product design system)
