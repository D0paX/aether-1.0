# Awesome React

- URL: https://github.com/enaqx/awesome-react
- Category: engineering
- Relevance: Comprehensive index of the React ecosystem for discovering tools, patterns, and libraries.
- Priority: supplementary

## Description

Awesome React is a community-maintained collection of resources related to the React
ecosystem. It covers React itself, state management, routing, forms, testing, styling,
performance optimization, server-side rendering, and the broader ecosystem of tools
and libraries built around React.

## Key Sections

- React general resources: Official documentation, release notes, community resources
- React tools: Development tools, testing utilities, build tools
- React frameworks: Next.js, Remix, Gatsby, and other React-based frameworks
- React state management: Redux, Zustand, Jotai, Recoil, and other state libraries
- React styling: CSS-in-JS, CSS modules, and styling approaches
- React component libraries: UI component libraries and design system implementations
- React testing: Testing libraries, strategies, and patterns

## Usage Guidelines for Aether

**Use as reference for:**
- Ecosystem discovery: When looking for a React library to solve a specific problem
  (drag-and-drop, virtualization, form validation), use this list as a starting point
- Pattern research: Study how different approaches to state management, styling, and
  testing are compared in the React ecosystem
- Best practices: Review current React best practices and conventions, especially
  around hooks, performance optimization, and TypeScript integration

**Do not adopt:**
- Any library without evaluating it against Aether's existing architecture decisions
  (React 19, Zustand, Framer Motion, vanilla CSS)
- Patterns from older React paradigms (class components, HOCs, render props) unless
  no hooks-based alternative exists
- Server-side rendering frameworks (Aether runs in Chromium WebUI, not a web server)
