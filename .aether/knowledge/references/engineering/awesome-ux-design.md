# Awesome UX Design

- URL: https://github.com/stevekrug/awesome-ux-design
- Category: engineering
- Relevance: Curated collection of UX design resources, tools, and methodologies for informing Aether's user experience decisions.
- Priority: supplementary

## Description

Awesome UX Design is a community-maintained list of UX design resources covering
research methods, design tools, accessibility guidelines, usability testing, information
architecture, and interaction design patterns. It provides a broad overview of the
UX discipline with links to tools, articles, and frameworks.

## Key Sections

- UX research: User research methods, survey tools, analytics platforms
- Design tools: Prototyping tools, wireframing tools, design collaboration platforms
- Accessibility: WCAG guidelines, accessibility testing tools, inclusive design resources
- Usability testing: Testing methodologies, remote testing tools, heuristic evaluation
- Information architecture: Navigation patterns, content organization, labeling systems
- Interaction design: Animation principles, micro-interaction patterns, feedback systems

## Usage Guidelines for Aether

**Use as reference for:**
- Accessibility standards: When implementing accessibility features in Aether,
  use this list to find current WCAG guidelines and testing tools
- Usability research: When evaluating Aether's UX decisions, reference the usability
  testing methodologies and heuristic evaluation frameworks listed here
- Interaction design patterns: Study established interaction patterns for common
  browser UI elements (address bars, tab management, bookmarks, history)

**Do not adopt:**
- UX methodologies designed for large product teams (Aether's development is
  primarily AI-assisted with project lead oversight)
- Enterprise UX tools and processes
- Any UX pattern that conflicts with Aether's Apple-inspired design philosophy
