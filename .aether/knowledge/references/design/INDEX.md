# Design References — Category Index

Visual design guidelines, resources, and systems that inform Aether's UI identity.

## Aether Design Context

Aether's design philosophy is Apple-inspired: Safari, macOS, visionOS, and the
Apple Human Interface Guidelines. References in this category define the visual
language, spacing systems, typography, and interaction patterns that Aether draws from.

Material Design is included as a secondary reference for its accessibility and
color system documentation, not for its visual style. Aether does not adopt
Material Design aesthetics.
