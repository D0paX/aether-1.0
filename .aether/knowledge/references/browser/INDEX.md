# Browser References — Category Index

Chromium and Brave source references that inform Aether's browser engine integration.

## Aether Browser Context

Aether is a fork of Brave Browser, which is itself a fork of Chromium. Understanding
the Chromium source tree, build system (GN + Ninja), WebUI framework, and Brave's
customization layer is essential for all browser-level work.

These are the most technically critical references in the entire knowledge system.
