# Linear

- URL: https://linear.app
- Category: product-design
- Relevance: Best-in-class example of application UI design, keyboard-first interaction, and the level of polish Aether aspires to.
- Priority: primary

## Description

Linear is a project management tool known for its exceptional UI quality, performance,
and attention to design detail. It is widely regarded as one of the best-designed
software applications in production. Linear demonstrates that productivity tools
can be both powerful and beautiful.

## Key Sections

- Application design: Overall layout, navigation, and information architecture
- Keyboard navigation: Comprehensive keyboard shortcut system, command palette
- Transitions and animations: Smooth, purposeful animations that enhance usability
- Typography and spacing: Consistent type scale, generous but not wasteful spacing
- Color system: Muted, professional color palette with clear visual hierarchy
- Command palette: Spotlight-style command interface for rapid navigation

## Usage Guidelines for Aether

Linear is a **primary product design reference**. When making UI design decisions
for Aether, Linear's implementation should be studied as a benchmark for quality.

**Use as reference for:**
- Keyboard-first design: Linear's keyboard navigation is comprehensive. Aether's
  browser chrome should have equivalent keyboard navigation quality.
- Command palette UX: Linear's command palette (Cmd+K) is a reference for how
  Aether's address bar and command interface should feel.
- Animation restraint: Linear uses animation purposefully — never decoratively.
  Every animation serves a functional purpose (orientation, feedback, continuity).
- Information density: Linear balances information density with readability. Aether's
  sidebar, tab bar, and toolbar should achieve similar balance.
- Loading states: Linear's skeleton screens and progressive loading patterns.

**Do not adopt:**
- Linear's specific color palette (Aether has its own brand identity)
- Linear's layout structure (project management layout differs from browser layout)
- Any Linear branding or visual identity elements
