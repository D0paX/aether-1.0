# Stripe

- URL: https://stripe.com
- Category: product-design
- Relevance: Reference for premium web design, documentation quality, and developer-facing UI design.
- Priority: secondary

## Description

Stripe is a payment infrastructure company known for exceptional web design and
developer experience. Its marketing site, documentation, and dashboard are
consistently cited as best-in-class examples of web design. Stripe demonstrates
how technical, complex products can be presented with clarity and visual sophistication.

## Key Sections

- Marketing site: Typography, gradient usage, layout composition, scroll animations
- Documentation: Information architecture, code example presentation, API reference design
- Dashboard: Data visualization, form design, table design, settings UI
- Checkout: Form UX, error handling, progressive disclosure
- Visual design: Color gradients, illustration style, typographic hierarchy

## Usage Guidelines for Aether

Stripe is a **secondary reference** for visual design quality and documentation
standards.

**Use as reference for:**
- Typography hierarchy: How Stripe establishes clear visual hierarchy through
  font size, weight, and color
- Settings UI: Stripe's dashboard settings demonstrate clean form layouts,
  section organization, and toggle/input patterns
- Documentation quality: If Aether publishes developer documentation (extensions,
  APIs), Stripe's documentation sets the standard for clarity and usability
- Gradient and color usage: Stripe's tasteful use of gradients (subtle, purposeful,
  never garish) as inspiration for Aether's accent treatments
- Error handling UX: How Stripe communicates errors, validation, and system status

**Do not adopt:**
- Stripe's specific visual identity (gradients, colors, illustrations)
- Marketing-oriented design patterns (hero sections, testimonials, pricing pages)
- SaaS dashboard patterns that do not apply to browser UI
- Stripe's animation style (Aether uses spring physics, not CSS transitions)
