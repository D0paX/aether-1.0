# UI Libraries — Category Index

Component libraries and UI frameworks that inform Aether's component architecture.

## Aether UI Context

Aether uses React 19 + TypeScript via Chromium WebUI. These UI library references
provide patterns for component API design, accessibility, composability, and
visual effects. Aether does not use these libraries directly — it builds its own
components — but their patterns and conventions inform the component architecture.
