# Aceternity UI

- URL: https://ui.aceternity.com
- Category: ui-libraries
- Relevance: Reference for premium animation patterns, 3D effects, and high-end visual treatments in React.
- Priority: supplementary

## Description

Aceternity UI is a collection of animated React components focused on premium visual
effects. It provides copy-paste components featuring 3D transformations, spotlight
effects, animated backgrounds, text effects, and complex interaction animations.
Components are built with Framer Motion and Tailwind CSS.

## Key Sections

- 3D effects: 3D card transforms, parallax scrolling, perspective effects
- Spotlight and glow: Cursor-following spotlights, glow borders, aurora backgrounds
- Text animations: Typewriter effects, text generation effects, sparkle text
- Card effects: Hover reveals, animated cards, moving borders
- Background components: Animated beams, vortex backgrounds, shooting stars

## Usage Guidelines for Aether

Aceternity UI is a **supplementary reference** for animation technique study.
Aether does not use Aceternity UI as a dependency.

**Use as reference for:**
- Framer Motion techniques: Aceternity components are built with Framer Motion,
  the same library Aether uses. Study how they compose animations, use variants,
  and manage animation state
- Spring animation parameters: Real-world spring configurations (stiffness, damping,
  mass) that produce premium-feeling motion
- Hover interaction patterns: Cursor-tracking effects, reveal animations, and
  interactive feedback that could be tastefully applied to Aether's UI
- GPU-accelerated transforms: How to structure animations using transform and opacity
  for smooth 60fps rendering

**Do not adopt:**
- Aceternity's visual style (tends toward dark, high-contrast marketing aesthetics)
- Tailwind CSS class-based styling
- Heavy 3D effects in the browser chrome (performance and usability concern)
- Any effect that draws attention away from web content
- Excessive animation that would feel gimmicky in a productivity tool
