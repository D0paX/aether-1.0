# Magic UI

- URL: https://magicui.design
- Category: ui-libraries
- Relevance: Reference for animated decorative components, landing page effects, and premium visual patterns.
- Priority: supplementary

## Description

Magic UI is a collection of animated React components designed for creating visually
impressive landing pages and marketing sites. It includes animated text effects,
particle systems, gradient backgrounds, border animations, and other decorative
components that prioritize visual impact.

## Key Sections

- Text animations: Typing effects, gradient text, text reveal animations
- Background effects: Particle systems, gradient meshes, dot patterns, grid backgrounds
- Border animations: Animated borders, shimmer effects, spotlight effects
- Layout components: Bento grids, marquees, animated lists
- Interactive elements: Magnetic buttons, tilt cards, 3D transforms

## Usage Guidelines for Aether

Magic UI is a **supplementary reference** for visual inspiration only. Aether
does not use Magic UI as a dependency.

**Use as reference for:**
- Animation techniques: How to create smooth gradient animations, particle effects,
  and text reveal sequences using Framer Motion and CSS
- Visual polish ideas: Specific visual treatments that could elevate Aether's
  new tab page, settings UI, or onboarding experience
- Performance patterns: How animated components manage requestAnimationFrame,
  GPU acceleration, and render performance

**Do not adopt:**
- Magic UI components directly (Aether builds its own)
- Marketing-oriented animations in the browser chrome (browser UI must be functional,
  not decorative)
- Heavy particle systems or background effects in performance-sensitive areas
- Any effect that would distract from web content viewing
