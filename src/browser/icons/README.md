# Icons — Aether Browser

Icons directory for Aether browser.

Placeholder icons are generated by `tools/scripts/generate-icons.ps1`.

Production icons must replace these before any public release.

## Required Sizes

| Format | Sizes (px)                          | Purpose                        |
|--------|-------------------------------------|--------------------------------|
| PNG    | 16, 32, 48, 64, 128, 256, 512      | Platform icons, tray, taskbar  |
| ICO    | 16, 32, 48, 256 (multi-resolution) | Windows executable icon        |

## File Naming Convention

- `aether_{W}x{H}.png` -- Individual PNG icons at each resolution.
- `aether.ico` -- Multi-resolution Windows icon file.

## Regenerating Placeholders

From the repository root:

```powershell
.\tools\scripts\generate-icons.ps1
```

## Replacing With Production Icons

When production artwork is ready:

1. Replace every PNG in this directory with the final artwork at matching dimensions.
2. Rebuild `aether.ico` from the 16, 32, 48, and 256 PNGs.
3. Update `tools/patches/` with a new patch that swaps Brave icons for Aether icons.
4. Run a full rebuild to confirm the icons appear in the compiled browser.
