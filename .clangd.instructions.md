# clangd Setup Instructions

## Generating compile_commands.json

clangd requires a compile_commands.json file to understand Chromium's include paths.

After running a build (Batch 03), generate this file by running from `C:\src\brave-browser\`:

```cmd
gn gen src/out/Debug --export-compile-commands
```

This creates `C:\src\brave-browser\src\out\Debug\compile_commands.json`.

## Pointing clangd to the compile commands

In `.vscode/settings.json`, add or confirm this setting:
```json
"clangd.arguments": [
  "--compile-commands-dir=C:/src/brave-browser/src/out/Debug"
]
```

## Restarting clangd

After generating compile_commands.json: open VS Code command palette (Ctrl+Shift+P) and run "clangd: Restart language server".

IntelliSense for C++ files in `src/browser/` will then be fully functional.
